# Model Router — Руководство оператора (краткое)

Версия: R12-B / R13 (2026-09-11). Полное руководство: docs/Model_Router_v1_0_Rukovodstvo_FINAL.pdf

## Как понять состояние системы

Откройте http://127.0.0.1:4111/admin-ui/ — вкладка «Обзор».

Ключевые цифры:
- ПРОВАЙДЕРЫ — сколько маркетплейсов подключено (норма: 2).
- МОДЕЛИ · В МОЁМ ПУЛЕ — модели, которые Router может выбирать автоматически.
- ДОСТУПНЫ СЕЙЧАС — модели с активными предложениями на рынке.
- МАРШРУТЫ ROUTER — конкретные пути «провайдер + модель» в runtime.
- РАСХОДЫ С МОМЕНТА ЗАПУСКА ROUTER — фактические траты (ACTUAL).

Если карточка показывает «Ошибка получения данных» — недоступен конкретный
endpoint; остальные цифры остаются достоверными.

## Как найти модель

Вкладка «Модели» → поле поиска → Enter. Фильтры: «В моём пуле» / «Все» /
«Доступные» и т.д.

## Как посмотреть цену

Откройте модель → вкладка «Цены»: официальная цена, лучшая цена сейчас,
скидка, ваш максимум по политике. Бейдж «Оценка» — цена из каталога,
«Фактически» — из биллинга провайдера.

## Как проверить доступность

Кнопка «Проверить доступность» на вкладке «Модели» — проверяет ТОЛЬКО модели
вашего пула (бесплатные проверки каталога), с прогрессом «N / всего».
Результат: «Доступна · 1.2 с» или причина (таймаут, ошибка авторизации).

## Как добавить модель в пул

1. «+ Добавить модель» → поиск по всем каталогам.
2. Выберите вариант провайдера (цена/контекст).
3. Название + canonical ID (предложен автоматически), минимальная скидка.
4. Проверка → Сохранить.

Или из «Новые и несопоставленные» → «Добавить как новую».

## Как задать минимальную скидку

Модель → вкладка «Политика» → «Свой минимум: 90%» → Сохранить.
Живой предпросмотр показывает: рынок сейчас vs ваш минимум (✓/✗).
Кнопка «Вернуть общее значение» сбрасывает наследование.

## Как убрать модель

Модель → внизу вкладки «Обзор»:
- «Убрать из пула» — Router не выбирает автоматически (обратимо);
- «Скрыть» — не показывается в списке (обратимо);
- «Отключить» — запрещена даже для fallback;
- «Удалить сопоставление» — только для ручных canonical-маппингов.

Физически удалить модель из каталога провайдера нельзя.

## Как увидеть расходы

«Обзор» → карточка «Расходы» (с момента запуска, кумулятивно) и таблица
«Состояние провайдеров» (запросы, траты, TTFT по каждому провайдеру).

## Как откатить конфигурацию

«Настройки» → раздел «Конфигурация и восстановление»:
- «Создать точку восстановления» — snapshot текущего состояния;
- «Сравнить с baseline» — предпросмотр diff перед применением;
- «Восстановить baseline» — возврат к сохранённому состоянию (с подтверждением).

Аварийный полный откат: docs/rollback.md + бэкап control.db
(model-router-data/control/control.db.bak-*).

## Служебное

- Runtime: 127.0.0.1:4100 (model-router.service)
- Control plane и UI: 127.0.0.1:4111 (model-router-control.service)
- Проверка: curl -s localhost:4100/health и curl -s localhost:4111/healthz
- Логи: journalctl --user -u model-router-control.service -e
- Тесты: cd ~/model-router && .venv/bin/python -m pytest gateway_tests -q
