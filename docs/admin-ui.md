# Admin UI (R12 — руководство администратора)

Served by the control plane at http://127.0.0.1:4111/admin-ui/ (same
origin as the admin API; no separate frontend build). Язык по умолчанию —
русский (переключение RU/EN в Настройках, localStorage `mr_lang`).

## Как читать интерфейс

### Цены
- «Официальная цена» — прайс вендора, $ за 1M токенов (вход / выход).
- «Лучшая цена сейчас» — самый дешёвый живой вариант среди провайдеров.
  Это ОЦЕНКА (marketplace ask), badge «Оценка».
- «Скидка» — насколько лучшая цена ниже официальной.
- Дешёвые цены не округляются до $0.00: ≥$1 → 2 знака, ≥$0.01 → 4, меньше — 6
  (например $0.0040).
- «Фактически» (badge ACTUAL) — сумма по реальному биллингу (Provider B
  x-si-buyer-cost-micro); появляется после живых запросов.
- Каждая цена имеет время среза («Обновлено 21:43»); устаревший срез
  помечается.

### Рынок / предложения / продавцы
- «Предложений: 17» — ценовые предложения (asks) Provider A; личность
  продавца неизвестна, input/output asks не считаются дважды.
- «Продавцов: 4» — реальные продавцы Provider B.
- Сумма по провайдеру в Dashboard — сумма по моделям, продавцы могут
  повторяться (подпись это явно говорит).

### Почему Router использует / не использует модель
Кнопка «Почему?» в карточке модели показывает построчные проверки:
сопоставлена, доступна на рынке, скидка vs минимум, в пуле, не скрыта,
контекст, health. Итог: участвует / не участвует в авто-выборе.

### Задержка
TTFT/latency показываются только из реальных данных: probes (inference)
и runtime-метрики. Недостаточно данных — «Недостаточно данных».

## Операции

### Добавить модель
«+ Добавить модель» → 5 шагов: поиск по всем каталогам → выбор варианта
провайдера → имя + canonical (предложен автоматически) + свой минимум
скидки → проверка → сохранение. Модель стартует «На наблюдении» (WATCH).

### Убрать / скрыть / отключить
- «Убрать из автоматического выбора» — модель остаётся в каталоге, Router
  её не выбирает (обратимо).
- «Скрыть» — не показывается в списке (обратимо).
- «Отключить» — запрещена даже для fallback.
- «Удалить сопоставление» — только для custom canonical mapping;
  provider-discovered модель физически удалить нельзя.
Все действия — через подтверждение, все попадают в журнал.

### Минимальная скидка
Настройки → глобальный минимум (по умолчанию 80%). Per-model: открыть
модель → вкладка «Политика» → «Использовать общий» / «Свой минимум».
Live-предпросмотр: рынок сейчас vs ваш минимум → «подходит» /
«сейчас не используется». «Вернуть общее значение» сбрасывает override.

### Несопоставленные модели
«Новые и несопоставленные» (badge 537): поиск, группировка по семейству
(Claude/GPT/Gemini/…), фильтры. Действия: сопоставить с существующим,
добавить как новую, игнорировать.

### Точки восстановления (baseline)
Настройки → «Конфигурация и восстановление»: создать точку восстановления
(immutable, SHA-256), сравнить с baseline (diff preview), восстановить
(через revision pipeline, не прямой записью в БД), экспорт/импорт JSON.
В baseline входят: providers, настройки, сопоставления, пул моделей,
политики (включая per-model), overrides. НЕ входят: secrets, метрики,
биллинг.

### Калькулятор стоимости
«Калькулятор стоимости»: модель, input/output/cache tokens, пресеты
(10k+2k … 1M+20k). Результат: лучший рынок сейчас, максимум по политике,
официальная цена, экономия ($ и %), сравнение по провайдерам.

### Расходы
Dashboard: «Расходы с момента запуска Router» — честная подпись
(телеметрия кумулятивна, per-request timestamps не хранятся).

### Журнал (Audit)
Человекочитаемые записи: дата/время, действие («Изменена политика модели
GPT-5.6 Luna»), автор, статус. Raw JSON — только «Для разработчика».

## Диагностический режим
Настройки → Диагностика (по умолчанию выключен): canonical ID, provider
model ID, score, raw JSON. Без него внутренние термины не показываются.

## Views (technical)
- Dashboard: semantic counters (routes vs market offers separately),
  provider state, spend, opportunities, alerts
- Providers: records, connect test, catalog/pricing refresh with diffs
- Models: main table (Модель / Используется / Доступность / Провайдеры /
  Предложения / Контекст / Цены / Скидка / Скорость / Выгодность /
  Действия), model drawer with tabs (Обзор / Провайдеры / Цены / Политика /
  История / Диагностика)
- Routing Policy / TaCHANGE_ME Policy / Overrides / Simulator
- Audit / Revisions / Settings

## Auth
Loopback callers are allowed; remote access requires the x-admin-token
header matching ADMIN_TOKEN (private env). The admin token is SEPARATE
from the inference token by design.

## E2E
`state/e2e/e2e_r12.py` (run with the nodriver venv): 36 steps — pages,
drawer click-outside matrix, responsive 1920/1366/1280/1024, user
journeys A–E, 0 console errors, 0 unexpected 4xx/5xx. Screenshots in
